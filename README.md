# claude-video-projects

Animated video experiments about a kid who grows ten times bigger. Each page is one self-contained HTML file.

| File | What it is |
| --- | --- |
| `crayon-story.html` | 2D crayon story, 44 seconds, six scenes |
| `ten-times-bigger-3d.html` | Interactive 3D toy town with a size slider |
| `ten-times-bigger-film.html` | 10-second 3D animated film |
| `video-styles-59.html` | 59 one-second looping style demos |
| `skills/comic-reel/SKILL.md` | The `comic-reel` skill for Claude |

## View online

In this repository open **Settings > Pages**, set **Source** to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save. After a minute the pages open at `https://ompugaonkar-bit.github.io/claude-video-projects/`.

## Use the skill

Zip the `comic-reel` folder, then in Claude open **Customize > Skills**, click **+**, then **+ Create skill**, then **Upload a skill**.

## Note

The style demos are procedural filters that imitate each look. They are not video files. To get an MP4, screen-record the page.
